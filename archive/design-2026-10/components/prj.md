## prj/project

| 项 | 内容 |
| --- | --- |
| 何时需要 | 按项目管理计划、里程碑与成本的客户 |
| 统一语言 | 项目；任务与里程碑；预算；成本归集；项目出账来源 |
| 拥有的数据 | 项目、计划、预算、成本归集结果、作为出账来源的里程碑与可出账额度 |
| 不变量 | 成本归集以来源事实（工时、报销、采购、领料）为依据，按事实 ID 去重；项目作为出账来源时由项目裁决可出账额度（协议 05） |
| 命令与查询 | 项目维护；里程碑完成；成本与预算查询 |
| 事件 | 里程碑完成；可出账额度变化 |
| 必需依赖 | `mdm/org`、`mdm/partner`、身份、授权 |
| 可选依赖与缺件 | `prj/timesheet`、`hrm/expense`、`erp/purchase`：成本来源；`erp/billing`：按里程碑出账 |
| 替换与 Fork | 成本分摊规则是替换点 |
| 范围 | 远期 |
| 验证故事 | 同一工时事实重复到达只归集一次；里程碑出账不重复 |

## prj/timesheet

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要记录与审批工时的客户 |
| 统一语言 | 工时单；期间；审批；费率 |
| 拥有的数据 | 工时单与审批状态 |
| 不变量 | 批准后的工时修改走修订重审；已关期间的工时更正顺延 |
| 事件 | 工时批准（成本事实来源） |
| 必需依赖 | `mdm/employee`、身份、授权 |
| 可选依赖与缺件 | `prj/project`：缺时工时不归集到项目 |
| 范围 | 远期 |
| 验证故事 | 员工离职后其未批工时按岗位重分配审批 |
