# 人事与薪资

> 边界卡，2026-10-13 候选。格式见[目录页](README.md)。基础员工与任职归 `mdm/employee`（D06）；本页的组件都引用它。适合按法人划分的能力（薪资）可以按法人并存多个实现，同一范围只有一个权威处理者（D16）。全部为远期。

## hrm/attendance

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要考勤、排班与加班管理的客户 |
| 统一语言 | 班次；排班；打卡；考勤结果；加班 |
| 拥有的数据 | 排班、打卡记录、考勤结果 |
| 不变量 | 考勤结果按工作日历与班次计算（协议 14）；已关账的考勤期间修改走更正 |
| 必需依赖 | `mdm/employee`、`mdm/org`、身份、授权 |
| 可选依赖与缺件 | 考勤设备适配：缺时手工或移动打卡 |
| 范围 | 远期 |
| 验证故事 | 跨夜班次的考勤归属正确的业务日期 |

## hrm/leave

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要请假与假期余额的客户 |
| 统一语言 | 假期类型；余额；请假单 |
| 拥有的数据 | 假期规则、余额、请假单 |
| 不变量 | 余额不为负（按规则允许透支的除外）；请假审批遵守职责分离（协议 09） |
| 必需依赖 | `mdm/employee`、`mdm/org`、身份、授权 |
| 可选依赖与缺件 | `infra/workflow`：缺时人工审批照常，任务在本组件页面中处理，没有统一待办入口（协议 09） |
| 范围 | 远期 |
| 验证故事 | 同时提交两张请假单，余额只扣一次足额的那张 |

## hrm/expense

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要员工费用报销的客户 |
| 统一语言 | 报销单；费用类型；票据；审批；支付 |
| 拥有的数据 | 报销单与明细、票据附件引用 |
| 不变量 | 审批不能由本人完成（D10）；批准后修改走修订重审（D33） |
| 命令与查询 | 提交、审批、支付申请 |
| 事件 | 报销批准（供财务形成应付员工款、供收付款付款） |
| 必需依赖 | `mdm/employee`、身份、授权、`infra/attachment` |
| 可选依赖与缺件 | `erp/payment`：缺时线下支付；`prj/project`：费用归集到项目 |
| 范围 | 远期 |
| 验证故事 | 报销人以第二个账号审批被拒；批准后改金额重审 |

## hrm/recruitment

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有招聘流程的客户 |
| 统一语言 | 职位需求；候选人；面试；录用 |
| 拥有的数据 | 需求、候选人与其个人资料（受限）、面试记录 |
| 不变量 | 候选人个人资料按保留期清理；录用后经员工组件入职，不在这里建员工 |
| 必需依赖 | `mdm/org`、身份、授权 |
| 可选依赖与缺件 | `infra/audit`（兼任证据存储）：个人资料清除的意图写入证据，缺时走外部告警通道（协议 15） |
| 范围 | 远期 |
| 验证故事 | 未录用候选人的资料到期清除 |

## hrm/appraisal

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有绩效目标与评价的客户 |
| 统一语言 | 考核周期；目标；评价；校准 |
| 拥有的数据 | 周期、目标、评价结果（受限字段） |
| 不变量 | 评价结果按敏感字段控制；周期关闭后修改需重开 |
| 必需依赖 | `mdm/employee`、身份、授权 |
| 范围 | 远期 |
| 验证故事 | 汇总报表中人数少于最小分组的部门不显示（协议 13） |

## hrm/payroll-core 与各国薪资（payroll-cn、payroll-us、payroll-es）

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要计算工资的客户；按法人所在国家选实现 |
| 统一语言 | 薪资期间；薪资项目；计算；薪资单；申报文件 |
| 拥有的数据 | 各法人的薪资规则、计算结果、薪资单 |
| 不变量 | 每个法人只有一个薪资实现是权威（D16）；同一期间计算可重算直到锁定，锁定后更正以调整表达 |
| 命令与查询 | 计算、锁定、发放申请、申报文件生成 |
| 事件 | 薪资锁定（供财务过账、收付款发放） |
| 必需依赖 | `mdm/employee`、`mdm/org`、`mdm/currency`、身份、授权 |
| 可选依赖与缺件 | `hrm/attendance`、`hrm/leave`：缺时由人工录入考勤与假期数据 |
| 替换与 Fork | 各国实现按法人选择；`payroll-core` 是否独立组件或是各国实现共用的库，在第一个国家实现设计时决定 |
| 部署 | 期间末批量计算 |
| 范围 | 远期 |
| 验证故事 | 法人甲用西班牙实现、法人乙用中国实现，互不干扰；锁定后的更正生成调整 |
