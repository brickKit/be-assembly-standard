# AI 路由测试（2026-10，针对 `docs/zh/` 正式文档）

> 开发文件。正式文档不链接本目录，本目录的内容也不得抄进正式文档（题目泄漏进文档，测试就作废）。依据：[AI 导航的怎样检验导航](../../docs/zh/01-conventions/05-ai-navigation.md#怎样检验导航)。旧题库针对旧英文文档，已归档。

## 测什么

一个对本项目零了解的 AI，只拿到项目路径与一句请求者的原话，能不能：

1. **找对路**：从根 `AGENTS.md` 出发，经正式文档（`AGENTS.md`、`README.md`、`docs/zh/`、`.claude/skills/`）找到回答这个请求的文件与小节；
2. **判对结论**：改动请求给出“落在哪个组件、要不要先改上游、要不要新组件、是否与已有决定冲突（冲突则停下交给人并引用出处）”；非改动请求直接作答；
3. **答对内容**：有该有的要点；没有与决定、规范相反的建议；没有编造的文件、命令或键。

## 考法

- 考场是仓库的副本，排除 `dev/`、`archive/`、`brickkit-feedback/`、`.git`；考生不读 brickKit 源码、组件源码（`components/*/backend` 等）与本机 `~/.claude/`。
- 每题只给请求原文；考生写出答案、结论、读过的文件与小节（按顺序）。
- 现有组件是旧设计的 2.x 实现（D59）；改动类问题按新设计（边界卡、协议）作答，不按旧代码。

## 评分

每题三项各 0–2 分：路径（必经文件与小节都读到 2；缺一项 1；没找到 0）、结论（正确 2；相邻 1；错误 0）、内容（必含要点全在且无违规 2；缺要点 1；有与决定相反的建议或编造 0）。满分 6。

**过关线**：总分不低于 80%，并且没有任何一题内容得 0。不过关时，按失分题找导航的缺口（路由表缺一行、链接指错、文档里找不到），修文档，不修题目。
