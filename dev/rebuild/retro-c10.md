## 4. 学到的东西放哪

- 代理缓存失败与 git 回退：kb知识库的“依赖管理”早就写了“没有 `git` 的构建环境要么在构建阶段装上 `git`，要么等缓存过期”；C7 的 R3 选了等，这次照它的推荐装上。不写反馈。
- `WaitGranted` 与 `UntilGranted` 的区别：SDK 自己守着（R3），不另记。
