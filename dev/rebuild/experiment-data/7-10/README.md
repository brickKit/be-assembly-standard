# T7.10 负载驱动的业务部分：冒烟（2026-10-23）

只验证负载驱动能按业务链出负载，不是性能测量：本机当时是省电模式（`powerprofilesctl get` 为 `power-saver`），没有切到性能模式，也没有成对、交替地比较。

- 格：D7-H（三个外壳；`be/go-core` 3.0.23 编进四个交易组件），灌好种子并跑过 L3 之后重新 `brickkit up`。
- 世界文件：`python -m cells world <格> <文件>`（be-acceptance 的 `conformance/cells/world.py`）：CN01、没有信用额度的 16 个客户、上海仓不追踪批次与序列号的 8 种货物（每种补到至少 100,000 件）。原样在 `world-D7-H.json`。
- 负载：`load -flow bill -rate 10 -warmup 5s -duration 30s`：每条链下单、确认、交货、草拟、开具，开环固定速率，延迟从该发出的时刻算。结果在 `D7-H-bill-10.json`。

| 计量的链 | 300 条，全部走完（错误率 0），吞吐 9.93 条/秒 |

| 之后 | 预热与计量共 350 张订单全部完成（出账正式化之后），350 张账单全部开具 |
