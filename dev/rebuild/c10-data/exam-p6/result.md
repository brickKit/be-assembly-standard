# C10 P6 一致性考试的结果

考生：一个没参与写作的子代理（2026-11-13），只读文件。答卷摘录在 `answer.md`。考试时格 C10-A 第二次从空库到 L3（`c10a-2`，47 全过）正在跑，所以考生看的是钉钉 3.0.2、通知 3.0.8。

## 必须改（7 条，全部处理）

| # | 发现 | 处理 |
| --- | --- | --- |
| M1 | 应用密钥在旧接口的地址里，钉钉不可达时随错误进日志 | 两层都改。钉钉 3.0.3：令牌改向新接口 `POST /v1.0/oauth2/accessToken` 取，密钥只在请求体里，取不到时的错误不带传输细节（单元测试 `TestTheSecretStaysOutOfURLsAndErrors`）。SDK alpha.133：出站的传输错误一律去掉地址的查询串与用户信息（`calls.withoutQuery`，`TestATransportErrorNeverRepeatsTheQuery`），旧接口地址里的短期令牌也不会经错误进日志 |
| M2 | 放弃时刻在 24 小时以后时，结果未知的命令转人工、永不终结 | 选（a）。线协议 alpha.130：P13.6、P13.14 写明带本地放弃时刻的 `unknown` 命令不转 `manual`，等到放弃时刻；向量 `external-command` 加两例（查询不可用超过人工时限、查到“不存在”而不能重发）。SDK alpha.133 的 `extcmd.Step` 照改（修之前这两例红） |
| M3 | 锁的顺序与条款相反 | 改条款（AI 定，待复核）：P17.17、P20.8 写成实际的“只有执行动作的路径锁授权、而且最先锁，再按单据、实例、任务”，并写明为什么不会死锁（签发只插入，别的路径都不锁授权行） |
| M4 | 钉钉组件没有任何清理 | 钉钉 3.0.3：每天的清理作业 `purge`（各模块清自己的表、一个事务）；迁移 0002 加索引；集成测试新步 `purge`（每种行过期的删、没过的留、停在 `received` 的回调不删） |
| M5 | 卡片标题没有转义 | 钉钉 3.0.3：`PlainText` 给卡片 Markdown 会解释的字符加反斜杠、换行与控制字符换成空格，标题与正文都用；单元测试；L3 断言模拟钉钉收到的标题已转义。模板字段实际怎样渲染，接真实钉钉前核对（设计的未决问题） |
| M6 | 协议 10 写渠道账号“从身份与员工信息同步、没有时退回站内” | 改成“本人经渠道的身份授权绑定（P20.9）；站内总是写，外部渠道没有账号时答没有渠道账号”；同节“渠道成员替换”一句同改 |
| M7 | 组件索引漏了动作事件的订阅方 | 采购 3.0.23、收付款 3.0.27 的清单在 `events.subscribes` 登记 `integration.im_dingtalk_action.recorded.v1`（注明按 `FLOW_ACTION_SOURCES`） |
