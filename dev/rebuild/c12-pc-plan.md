# C12：`frontend/pc` 的子计划

阶段“按依赖顺序重建其余组件”的第十二项（[components-plan.md](components-plan.md) 的 C12）：PC 办公入口。数据与考试放 `c12-data/`。

## 依据与牵动

- 边界卡 `docs/zh/07-components/frontend.md` 的 `frontend/pc`：
  - 不变量：按客户基线组合页面模块；页面不接触令牌。
  - 必需依赖：身份（会话）、边缘入口、所选页面模块对应的后端组件。
  - 部署：静态资源由边缘或静态文件服务提供。
  - 验证故事：没装库存时没有库存菜单；用户无权的菜单不显示，后端也拒绝直接访问。
- 协议 20：
  - 入口与页面模块：声明所需能力、菜单、权限键与文本；构建时按客户基线组合；`features` 由装配工具生成、边缘只给已登录会话。
  - 浏览器会话：身份成员持有会话，边缘缓存令牌并注入；`BE-Request`、`BE-Polling`；`TOKEN_STALE` 由边缘重换重放。
  - 权限、缺件与错误的显示表；统一待办的动作直发所属组件。
  - 断网草稿（D24）。
- 前端技术栈 `docs/zh/04-foundations/04-frontend-stack.md`：
  - 技术栈：Vue 3、TypeScript、Ant Design Vue、vxe-table（包在 `<BeTable>` 后）、ECharts。
  - 导航：两层导航、四种页面模板、四项用户偏好、CSS 变量令牌。
  - 写法：精确版本、只用 Composition API、lint 强制、从契约生成客户端。
- 测试：FE-1（逻辑）、FE-2（共享组件）、FE-3（端到端）、FE-4（视觉回归）。**跑 FE-3、FE-4 之前先问维护者**（测试与验证，第 121 行）。
- C11 留下的：边缘第一次放到格前面，bff 经边缘的一段（会话、`BE-Request`、`BE-Polling`）在这里补验（A176）。
- 现状（2026-11-20 读）：
  - 仓库 `brickKit/frontend-pc`：主分支只有 README，旧版（1.x，`apps/pc` 与 `apps/mobile` 的单仓）在 `legacy/v1`，只作参考。
  - `be-edge`（Traefik 插件）与 be-ops 的 `features` 已有，T6 实验在真实 Traefik 上跑过整条登录。
  - 身份成员有 `/api/iam/login`、`/callback`、`/logout`；**没有“我能做什么”的接口**：授权组件的用户面只有管理路由（P0 发现的源头缺口）。

## P0：首批范围（AI 定，待复核）

| 项 | 首批 | 理由 |
| --- | --- | --- |
| 仓库划分 | 一个仓库 `frontend-pc`，pnpm 工作区。包有：`ui-kit-pc`（第三方 UI 只在这里）、`api`（从各组件契约生成的客户端与类型）、页面模块（每个后端组件一个包，`modules/<组件>`）、`shell`（外壳应用：登录态、服务选择器、菜单、标签页、命令面板、法人切换、偏好）、`build`（按客户基线组合）。设计令牌放 `ui-kit-pc`，移动端照同一组种子值自带一份，由检查核对 | 协议 20 把仓库划分留给重建计划；不新建仓库（新建仓库要维护者）；单仓里改共享包与页面一起提交 |
| 首批页面模块 | 统一待办（我的待办、已办、任务详情、同意与驳回直发所属组件）、通知（我的消息、已读）、业务伙伴（列表、详情）、产品（列表、详情）、销售订单（列表、详情）、采购申请与订单（列表、详情、提交）、库存（可用量查询） | 覆盖四种页面模板与审批这条跨组件的路径；库存给验证故事“没装库存时没有库存菜单” |
| 不在首批 | 各组件的维护表单全集、报表、导入、打印预览、管理与授权的页面 | 页面模块的格式定下、首批跑通之后按组件逐个加 |
| 断网草稿 | 首批的一个表单（采购申请）接上草稿规则（按入口、用户、法人、表单隔离；联网后确认提交）；其余表单随后照同一个组合函数 | D24 是入口的不变量，要在第一个表单就定下做法 |
| 部署 | BrickKit 组件，镜像是静态文件服务；边缘把 `/` 路由给它，`/api/<名字>/` 路由给各组件 | 卡片写“边缘或静态文件服务”；作为组件才能被客户基线选择与升级 |

## 全局约束

照 [c11-bff-plan.md](c11-bff-plan.md) 的全局约束；另外：
- Node 与 pnpm 用本机已装的版本（装之前先查同类工具，例如 fnm），`package.json` 写精确版本、锁文件进仓库。
- 浏览器只用无头模式，不在维护者的桌面上开窗口。
- 新依赖取当前受支持的最新稳定版本，版本与理由记进设计。
