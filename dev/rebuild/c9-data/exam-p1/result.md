# C9 P1 考设计的结果

考生：一个没参与写作的子代理（2026-11-13），10 题，答卷 `answer.md`。读的是协议 12、线协议第 19 章草稿、附件组件的设计、子计划与安全 09a 的附件类别。25 条发现，处理如下（附件组件的设计据此整份重写）：

| # | 发现 | 处理 |
| --- | --- | --- |
| P-1 | 严格类别转发字节没规定响应头：上传的 HTML、SVG 在应用域名下执行 | AT06 固定 `attachment`、`nosniff`、`CSP: sandbox`，非图片与 PDF 一律 `application/octet-stream`；采购的类别不收 SVG、HTML |
| P-2 | 预签名用的主机名没有配置键，与 P6.14 冲突；浏览器直传的跨源规则没人管 | 第 02 章加 `OBJECT_STORE_PUBLIC_URL`，P19.6、P19.7 用它签；跨源规则与暂存前缀的过期规则写进部署要求，格的初始化随 P7 |
| P-3 | 采购只给严格下载查了字段资格 | 上传要修改操作、列表按字段资格过滤、下载要类别字段的读取资格；`invoice_scan` 是受限字段 |
| P-4 | 解除引用与擦除漏了进行中的状态 | 状态表：除 `purged` 外任何状态都能解除与擦除；进行中的会话与待定版本作废 |
| P-5 | 目录整份替换丢了旧类别版本 | 附件存类别快照（敏感级别、上限、类型、保留类别） |
| P-6 | 采购取消不给起算日期 | 取消与完成时给起算日期 |
| P-7 | 年限按类别名给；类别名没前缀 | 按保留类别给；类别名带领域（`erp.purchase.order_contract`） |
| P-8 | 凭证作废不原子 | 条件更新，与状态变化同一事务 |
| P-9 | 目录未同步时误拒并写假安全事件 | 答可重试的 `DEFINITION_PENDING`，不写安全审计 |
| P-10 | 没有最长保留 | `ATTACHMENT_RETENTION` 给最短与最长；最长到了仍挂着时告警，销毁由属主下令 |
| P-11 | 旧版本、被拒与隔离版本的对象没人删 | 清除删全部版本；被拒与隔离的 30 天后删 |
| P-12 | 上传未完成就确认会被拒 | 先查暂存对象，不在答可重试，不消耗凭证 |
| P-13 | `finalizing` 时限与重做的互斥没写 | 10 分钟；每分钟的工作按条件更新认领 |
| P-14 | 对象缺失时报告成不存在；与隔离混在一起 | 新状态 `missing`，签发前查元数据；对象回来转回 |
| P-15 | 复制与浏览器直传没有可信摘要；复制沿用客户端的元数据 | P19.2 写明只有端口放入的有摘要；P19.4 复制时重写元数据；附件读内容自己算 |
| P-16 | 存储连条件放入都不遵守时会退成无条件写 | P19.3：首次使用时探测，不遵守的拒绝一切条件写入并告警 |
| P-17 | 属主读内容自己转发的命令没有 | 首批不做，写进未决问题 |
| P-18 | 保全范围不到“某客户全部合同” | 首批不做，写进未决问题 |
| P-19 | 文件名在预签名地址里会进日志 | P19.10：端口不把预签名地址写进日志 |
| P-20 | 解除引用后已签出的地址的窗口没声明 | AT08 声明（5 分钟） |
| P-21 | 20 MiB 与分段阈值、首批不分段冲突 | 采购的上限改成 16 MiB 与 10 MiB |
| P-22 | 暂存前缀的过期没人管 | AT12 删到期会话的暂存对象；部署另设过期规则 |
| P-23 | 恢复到“原状态”没存；清除后版本行留不留 | 存解除引用前的状态；清除后行保留、对象删掉 |
| P-24 | 清除意图进证据存储 | 首批只写审计，随 C14 的整套恢复演练补（未决问题） |
| P-25 | 扫描从关闭改为开启后旧附件怎样 | 仍可用、标未扫描，按批补扫 |
