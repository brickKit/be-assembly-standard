# 基础能力

边缘入口、数据库、消息系统、对象存储与观测后端是基础资源，不是组件；独立证据存储由 `infra/audit` 兼任，见[部署与资源](../04-foundations/01-deployment-and-runtime.md)与[协议 15](../06-protocols/15-backup-and-recovery.md)。

## infra/iam-casdoor

| 项 | 内容 |
| --- | --- |
| 何时需要 | 所有部署都需要一个身份适配成员；选 Casdoor 作为身份提供方时用它 |
| 统一语言 | 账号；登录与会话；令牌（访问、刷新、服务）；外部身份源；签名密钥集合 |
| 拥有的数据 | 浏览器会话与其令牌（[协议 20](../06-protocols/20-frontend.md#登录与会话)）、账号与外部身份的绑定、服务令牌的签发记录（部署选用身份成员签发服务令牌时；默认的服务身份是部署信任域签发的证书，安全 02）、签名密钥（含预先发布的备用密钥，协议 19） |
| 不变量 | 令牌类型不能互换；登出与停用时向边缘推送失效，最坏由令牌有效期界定；刷新在会话锁内只做一次；旧刷新令牌再次使用时撤销整串 |
| 安全来源与恢复 | 作为授权的内部来源（产品提供变更序号或管理事件的方式待代表部署实验核实，核实前按外部来源的 `D_source` 声明，安全 03）：收到补取请求时先向产品拉取截至此刻的账号变更（产品的变更序号、管理事件或全量状态比较），写入发件表后再写回声，拉取失败时不写回声；另按 `P_pull`（起始 1 分钟）定期拉取；拉取到的停用与经本组件提交的停用都由本组件记证据（协议 15）；本组件是**水位来源**（协议 02）；高可用部署中全部写入同步提交（D66，协议 15）；以自己记录的停用（含产品坐标）为准：只有产品坐标中晚于本地记录的启用类变更才认作重新启用，否则判为产品回退，重新停用并告警（安全 03）；整套恢复后结束恢复前创建的全部会话（含身份产品的会话），撤销刷新令牌，按证据强制凭据收紧过的主体重设密码与 MFA（协议 15） |
| 命令与查询 | 登录回调、会话的令牌签发（边缘按会话缓存，D61）与失效推送、登出；服务令牌签发（部署选用这条路线时）；公钥集合；补取（水位探测：只对声明订阅的服务身份开放，返回到回声为止的变更；[协议 02](../06-protocols/02-projections.md#来源水位)） |
| 事件 | 账号停用、会话撤销；水位回声（作为授权的内部来源，安全 03） |
| 必需依赖 | Casdoor（基础资源）、数据库 |
| 可选依赖与缺件 | 外部身份源（企业目录）：按客户；`mdm/employee`（只经事件：订阅入职事件开通账号）：缺时人工开通；`infra/audit`（兼任证据存储）：缺时停用的意图走外部告警渠道（协议 15） |
| 替换与 Fork | 与 `infra/iam-keycloak`、通用 OIDC 适配互为单选替换；切换协议见[安全 11](../06-protocols/security/11-identity-member-switching.md) |
| 部署 | 边缘缓存会话令牌，它不在每个请求的同步路径上；短暂重启只影响新登录与令牌续期；作为授权的内部来源，本组件或身份产品自身停机、升级超过 `D_src_high`（起始 60 秒）时高风险操作暂停（D64）。边缘的令牌缓存与失效推送由本组件随附的边缘插件或旁挂进程实现，列入代表部署实验；单跑或外壳 |
| 适用协议 | 安全 02、08（紧急访问的认证路径）、19（密钥）、20 |
| 范围 | 当前重建 |
| 验证故事 | 多标签页同时刷新只刷新一次；停用账号后失效推送到达即拒绝浏览器请求，推送丢失时不晚于令牌有效期，授权侧不晚于 `D_src_high` + W；在 Casdoor 控制台直接停用账号，补取或定期拉取时被拉取并记证据；签名密钥泄露后立即切换到备用密钥 |

## infra/authz

| 项 | 内容 |
| --- | --- |
| 何时需要 | 所有部署 |
| 统一语言 | 权限键目录；角色；完整授予与段；管理上限；任职关联授予；共享与委托；视图与核验；能力声明 |
| 拥有的数据 | 安全记录（授予、角色、共享、委托、扮演会话，安全 08）、权限目录、视图与版本、严格路径的接受记录（启用时） |
| 不变量 | 记录是权威，引擎只是索引（安全 10）；管理授出不超出上限（安全 07 的包含证明）；Authz 内的普通变更不能移除最后一个可用管理员；来源侧的离职与停用照常生效，无可用管理员时进入待恢复（安全 08、D62） |
| 安全来源与恢复 | 高可用部署中全部写入同步提交（D66）；整套恢复时按原提交序号重放证据，重放全部结束后才判定可用管理员是否为零（协议 15） |
| 命令与查询 | 授予、撤销、批量计划；视图下发与核验（安全 03）；查询编译所需的段；能力声明 |
| 事件 | 安全记录变更（收紧先在事务外写意图证据，提交后经发件表写结论，协议 15） |
| 必需依赖 | 身份、数据库 |
| 可选依赖与缺件 | `mdm/org`：经投影取得法人与部门维度，缺时这两个维度不可用（授予只能用其余维度）；`mdm/employee`：缺时任职关联授予不可用；`infra/audit`（兼任证据存储）：收紧的意图在本地事务之外写入；缺或不可达时收紧照样生效，完整记录进入外部告警（协议 15）。内部来源都按水位探测取得新鲜度（安全 03） |
| 替换与 Fork | 与 `infra/authz-static`、`infra/authz-openfga` 及策略引擎成员按能力矩阵替换（安全 10） |
| 部署 | 每个请求都读它下发的视图；可用性重要；单跑或外壳 |
| 适用协议 | 安全 01–10、协议 03、15 |
| 范围 | 当前重建 |
| 验证故事 | 撤权后不晚于视图有效期生效；越权授出被拒；成员切换前后摘要等价 |

## infra/workflow

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有人工审批或待办的客户 |
| 统一语言 | 待办（任务投影）；共享任务契约；动作入口；处理结果；历史 |
| 拥有的数据 | 来自各流程管理方的任务投影与历史 |
| 不变量 | 不保存决定、不转发动作、不在本地关闭任务；只订阅共享任务契约，只接受部署为该任务类型选定的流程管理方发布的投影（协议 09），不需要知道任何业务组件的地址；用户的动作由前端直接发给任务所属的组件，幂等与结果由所属组件负责，显示以其发布的任务投影为准（[协议 09](../06-protocols/09-approval-and-workflow.md#统一待办)，D68） |
| 命令与查询 | 我的待办、已办；每个任务的所属组件与动作入口（供前端直接提交） |
| 事件 | 无业务事件（只消费任务投影） |
| 必需依赖 | 身份、授权 |
| 可选依赖与缺件 | 通知：缺时没有提醒，只在待办中显示；流程管理方（下游，按共享任务契约发布任务、接收用户动作）：缺时没有对应的任务 |
| 替换与 Fork | 同契约的待办实现可替换；简单流程在业务组件内（SDK 的流程内核），可选流程引擎另有适配组件（选定产品后登记身份） |
| 部署 | 低到中负载；适合外壳 |
| 适用协议 | 02、09、13（摘要字段掩码） |
| 范围 | 当前重建；身份保留，职责改为统一待办（D19），不再拥有审批流程 |
| 验证故事 | 在待办中点同意后超时，显示结果未确认，重试只有一个决定（所属组件按幂等键处理）；所属组件不可达时显示投影并标明可能不是最新；新业务组件上线不需要改动或重新发布待办 |

## infra/attachment

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要在单据上附文件的客户 |
| 统一语言 | 附件；父记录；类别（属主声明）；访问凭证（属主申请、附件组件生成）；上传会话；最终键；扫描结果；解除引用；清除 |
| 拥有的数据 | 附件记录与对象（[协议 12](../06-protocols/12-attachments-and-object-storage.md)） |
| 不变量 | 下载的内容就是扫描为干净的内容；上传与下载只凭父记录的属主经系统面申请的短期凭证（绑定用户、附件或上传会话、操作、内容版本与有效期），附件组件核对申请者是父资源类型的属主，从不调用属主（D68）；严格敏感类别每次请求需新的凭证，或由属主转发内容；保全中不清除 |
| 命令与查询 | 申请上传会话、申请下载、列出父记录的附件（属主经系统面）；确认、下载（用户凭凭证）；解除引用、恢复、清除（属主的命令，含父记录的删除、销毁与擦除） |
| 事件 | 附件状态 |
| 必需依赖 | 对象存储（基础资源）、身份（服务身份与用户令牌）、授权（定义目录中的附件类别） |
| 可选依赖与缺件 | 扫描引擎：开发环境可关闭并标明未扫描；`infra/audit`（兼任证据存储）：清除的意图写入证据，缺时走外部告警渠道（协议 15）；父记录的属主（下游，经契约调用本组件并签发凭证） |
| 替换与 Fork | 同契约实现 |
| 部署 | 大文件处理占用带宽与内存；按负载单跑 |
| 适用协议 | 03、11、12、15 |
| 范围 | 当前重建 |
| 验证故事 | 确认后再次上传不改变最终内容；撤权后已签出的链接在有效期后失效；凭证过期、被篡改或用于另一附件时被拒；新业务组件上线不需要改动或重新发布附件组件 |
