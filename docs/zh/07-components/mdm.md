# 主数据

主数据组件被所有业务组件读取（经投影或批量查询），自己不调用业务组件；它们的状态变化以事件发布（[协议 02](../06-protocols/02-projections.md)），引用按[协议 07](../06-protocols/07-references.md)。

## mdm/partner

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有销售或采购业务的任何客户；只用人事或项目的客户可以不装 |
| 必需依赖 | `mdm/org`（法人）、身份、授权 |
| 可选依赖与缺件 | 附件（证照）：缺时不能上传资料文件；`infra/audit`（兼任证据存储）：销毁与擦除的意图写入证据，缺时走外部告警渠道（协议 15） |
| 范围 | 当前重建；承接 `mdm/customer`、`mdm/supplier`（退役）；信用额度不在这里（`erp/credit`），CRM 私有关系不在这里（`crm/customer`） |
| 设计 | 已重建：统一语言、拥有的数据、不变量、命令与查询、事件、依赖、实现状态与验证故事在组件仓库的 [docs/design.md](../../../components/mdm/partner/docs/design.md)；用法、部署与配置在 [BRICKKIT.md](../../../components/mdm/partner/BRICKKIT.md) |

## mdm/employee

| 项 | 内容 |
| --- | --- |
| 何时需要 | 按岗位或任职分配审批、授权（D09）的客户；所有 HR 扩展；小客户只按账号与角色管理时可以不装 |
| 统一语言 | 员工；工号；在职状态；任职（法人、部门、岗位、有效期）；员工与账号的映射（非一一对应） |
| 拥有的数据 | 员工、任职实例、员工与账号的映射、员工与其收款伙伴（员工往来角色）的映射、敏感的个人资料（受限字段） |
| 不变量 | 任职有效期不重叠于同一岗位的同一人（按声明）；离职生效后所有任职结束；账号与员工关联的建立与变更需要受保护操作的确认（确认记录在 Authz，安全 08）；办理离职时，若此人是最后一名可用的授权管理员，提示但不阻止（D62） |
| 安全来源与恢复 | 离职、任职结束与账号关联的结束先在事务外写意图证据，再提交，变更历史记录证据身份与版本（协议 15），整套恢复后依据证据重新办理；发件行在锁内按提交后编号，发布位置带纪元，事件只含可投影字段（协议 02）；本组件是**水位来源**（协议 02）；高可用部署中全部写入同步提交（D66，协议 15） |
| 命令与查询 | 入职（可由招聘的录用发起，建立预入职员工；身份适配组件订阅入职事件，按客户配置自动开通账号或提示身份管理员开通，账号与员工的关联仍是受保护操作）、调岗、离职（生效日期）；本人资料变更申请（远期，员工自助）；开通员工往来（经伙伴的接口，业务确认，D69）；收款伙伴查询；任职查询（某人当前持有的岗位、某岗位的持有人）；补取（水位探测：只对声明订阅的服务身份开放，返回到回声为止的变更；[协议 02](../06-protocols/02-projections.md#来源水位)） |
| 事件 | 员工、任职与账号关联的状态事件；任职开始与结束（驱动授权的任职关联授予，D30；驱动审批任务重分配，协议 09）；水位回声（作为授权的内部来源，安全 03） |
| 必需依赖 | `mdm/org`、身份、授权 |
| 可选依赖与缺件 | `infra/audit`（兼任证据存储）：缺时收紧的意图走外部告警渠道（协议 15）；`mdm/partner`：员工作为收款对象（报销、薪资发放），缺时报销与薪资只能线下支付；离职生效时，员工组件经伙伴接口**暂停**员工往来角色（不再接受新的报销与薪资引用，已有未清项照常结算），退役由财务在未清项结清后经伙伴接口发起，或转为人工待办；主数据不读取财务 |
| 替换与 Fork | 同契约实现；与外部 HR 系统同步时以适配器写入 |
| 部署 | 读多写少；适合外壳 |
| 适用协议 | 02、07、08、13、16（导入与期初任职）、安全 02、04、08（任职与授予的联动） |
| 范围 | 当前重建（新身份，D06） |
| 验证故事 | 审批人离职，待处理任务按岗位转给接任者；调岗后旧任职关联的授予自动撤销，新授予待确认（D30）；一人两个账号映射到同一员工，职责分离按人检查 |
