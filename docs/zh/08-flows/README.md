# 业务流程

端到端的业务过程：一件业务从开始到结束经过哪些组件、按什么顺序、靠什么衔接。每页只写到步骤、组件与衔接方式，规则在链接的协议与边界卡里。

用法：要知道“这一步在哪个组件做”或“改这一步会牵动谁”时，从这里找到步骤，再顺着“规则在哪”一列下到协议或组件。组件本身见[组件索引](../00-overview/09-component-index.md)。

| 流程 | 回答 |
| --- | --- |
| [订单到收款](order-to-cash.md) | 报价、确认与预占、出库、出账、应收、收款、核销、关账；成本一支；服务订单、现款、款到发货、退货等变体 |
| [采购到付款](procure-to-pay.md) | 申请与订单、收货入库、暂估、三单匹配与应付、成本调整、付款、核销、关账；预付、服务验收、无订单票据、采购退货等变体 |
