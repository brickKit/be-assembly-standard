# 0404 用户偏好只有四项

## 决策

用户只能设置四样东西：收藏的组件、亮色 / 暗色 / 跟随系统、密度、语言——外加表格列状态（列宽、列序、隐藏列），只存在本地、不同步。主色、logo、产品名、水印和灰度模式是部署的组装期配置。不提供布局模式切换。

## 理由

用户每多一个可切换的展示选项，要测试的页面就成倍增加；没有真实客户会去切换布局。收藏和列状态才是 ERP 用户每天真正在用的；品牌是公司制度，不是个人选择。

## 挡下什么

- "让用户选侧边栏 / 顶栏 / 混合布局"
- 每个用户自选主题色或 logo
- 照抄 admin 模板的设置面板（圆角、动画、页脚、面包屑开关）
- 只为存偏好而新建一个后端服务或仓库

## 何时重新讨论

多个真实客户都要求同一个额外偏好项时。
