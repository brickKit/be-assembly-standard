# 协议

本目录是完整的设计：每份协议回答一组具体的问题，写明采用的做法与理由、状态迁移表与时序图、参数起始值、参考模型的结论与没有覆盖的条款，以及独立预期（固定的场景与结果，实现阶段每条至少一个测试）。权限与安全在 [security/](security/README.md)。

底层的选择与推荐组合在 [04-foundations](../04-foundations/README.md)；组件的边界在 [07-components](../07-components/README.md)；运维操作在 [05-operations](../05-operations/README.md)。
