# 主数据

> 边界卡，2026-10-13 候选。格式见[目录页](README.md)。主数据组件被所有业务组件读取（经投影或批量查询），自己不调用业务组件；它们的状态变化以事件发布（[协议 02](../protocols/02-projections.md)），引用按[协议 07](../protocols/07-references.md)。

## mdm/partner

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有销售或采购业务的任何客户；只用人事或项目的客户可以不装 |
| 统一语言 | 业务伙伴（企业或自然人）；角色（客户角色、供应商角色，按法人开通）；正式联系人；地址；税号；伙伴银行账户（对方的收款账户）；合并与别名 |
| 拥有的数据 | 伙伴身份与基础资料、角色与角色资料（缺省币种、付款条件等）、正式联系人与地址、伙伴银行账户、合并记录与别名、墓碑 |
| 不变量 | 身份永不复用；已合并或已销毁的伙伴不接受新的资格引用；合并不成环；角色只能在已存在的法人下开通；同一国家的税号重复时提示并走人工合并（D22） |
| 命令与查询 | 新建与修改伙伴；开通、暂停、退役角色；合并与拆回（需要业务确认，人工确认，D22）；资格查询（“能否在法人乙向某伙伴销售”）；批量解析（当前数据、别名、墓碑、不存在、不可见） |
| 事件 | 伙伴与角色的状态事件（可覆盖状态）；已合并；已销毁（附擦除类别） |
| 必需依赖 | `mdm/org`（法人）、身份、授权 |
| 可选依赖与缺件 | 附件（证照）：缺时不能上传资料文件；`infra/audit`（兼任证据存储）：销毁与擦除的意图写入证据，缺时走外部告警通道（协议 15） |
| 替换与 Fork | 同契约的实现可接替；客户特有字段用扩展字段（协议 08） |
| 部署 | 读多写少；适合外壳 |
| 适用协议 | 02、07、08、11（在线可变，不转层）、13（数据集）、16（导入模板与期初）、安全 01–09 |
| 范围 | 当前重建范围；承接 `mdm/customer`、`mdm/supplier`（退役）；信用额度不在这里（`erp/credit`），CRM 私有关系不在这里（`crm/customer`） |
| 验证故事 | 同一企业既是客户又是供应商，应收应付各自独立；法人乙未开通客户角色时下单被拒；重复客户人工合并后历史订单显示原快照与“已并入”；合并后原客户的共享不自动转到存续客户 |

## mdm/product

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有销售、采购、库存或制造业务的客户 |
| 统一语言 | 产品（库存商品、服务、非库存物品）；分类；单位与单位分类；产品专属换算；追踪政策（批次、序列号）；按法人可售、可采购 |
| 拥有的数据 | 产品与分类、单位目录与换算（[协议 14](../protocols/14-data-foundations.md#金额数量汇率与单位)）、追踪政策、按法人的可售与可采购状态、条码 |
| 不变量 | 产品类型决定是否参与库存；已有库存流水的产品不能改变追踪政策或基本单位（需新产品并迁移）；产品专属换算优先于通用换算 |
| 命令与查询 | 新建与修改产品；按法人开通可售／可采购；资格查询；批量解析 |
| 事件 | 产品状态事件；单位与换算变化 |
| 必需依赖 | `mdm/org`、身份、授权 |
| 可选依赖与缺件 | 附件（图片）；缺时不能上传图片 |
| 替换与 Fork | 同契约实现；行业属性用扩展字段 |
| 部署 | 读多写少；适合外壳 |
| 适用协议 | 02、07、08、13、14、16、安全 01–09 |
| 范围 | 当前重建范围；标准成本移到 `erp/costing`（计价政策的输入），产品只保留物理与交易属性 |
| 验证故事 | 服务产品下单不请求库存；有流水的产品改追踪政策被拒；箱与件的换算按产品专属值 |

## mdm/org

| 项 | 内容 |
| --- | --- |
| 何时需要 | 所有客户（法人与组织是授权范围、账簿、单号的基础） |
| 统一语言 | 法人（时区、本位币、年度起始月）；部门树与部门路径；岗位；汇报关系；地点；工作日历 |
| 拥有的数据 | 法人资料、部门、岗位、汇报关系、地点、工作日历（按法人与地点的变体）及其版本；审批截止等按创建时的日历版本计算（协议 09） |
| 不变量 | 法人建立时必须指定时区与本位币（协议 14）；部门树无环；部门路径随移动更新且历史可追溯；会计期间与关账不在这里（D05，归财务）；收紧性的组织调整（撤销组织、移出上级、缩小范围）先在事务外写意图证据，再提交（协议 15）；发件行在锁内按提交后编号，发布位置带纪元，事件只含可投影字段（协议 02）；本组件是**水位来源**（协议 02）；高可用部署中本组件的收紧事务同步提交到备库（D65，协议 15） |
| 命令与查询 | 法人与组织的维护；组织变更（生效日期）；部门路径与上级查询；工作日历查询（某日是否工作日、加 N 个工作日）；补取（水位探测：只对声明订阅的服务身份开放，返回到回声为止的变更；[协议 02](../protocols/02-projections.md#来源水位)） |
| 事件 | 法人、部门、岗位、汇报关系的状态事件；工作日历版本；水位回声（作为授权与资格判断的来源，协议 02） |
| 必需依赖 | 身份、授权 |
| 可选依赖与缺件 | `infra/audit`（兼任证据存储）：缺时收紧的意图走外部告警通道（协议 15） |
| 替换与 Fork | 同契约实现；复杂矩阵组织可 Fork |
| 部署 | 读多写少；适合外壳 |
| 适用协议 | 02、07、13、14、16、安全 01–09（部门路径是数据范围维度） |
| 范围 | 当前重建范围；员工与任职不在这里（`mdm/employee`） |
| 验证故事 | 部门调整后，基于部门的数据范围按新路径生效；新建员工未分配部门时，`org` 维度不匹配任何行；法人在西班牙，业务日期按 Europe/Madrid |

## mdm/employee

| 项 | 内容 |
| --- | --- |
| 何时需要 | 按岗位或任职分配审批、授权（D09）的客户；所有 HR 扩展；小客户只按账号与角色管理时可以不装 |
| 统一语言 | 员工；工号；在职状态；任职（法人、部门、岗位、有效期）；员工与账号的映射（非一一对应） |
| 拥有的数据 | 员工、任职实例、员工与账号的映射、敏感的个人资料（受限字段） |
| 不变量 | 任职有效期不重叠于同一岗位的同一人（按声明）；离职生效后所有任职结束；账号与员工关联的建立与变更需要受保护操作的确认（确认记录在 Authz，安全 08）；办理离职时，若此人是最后一名可用的授权管理员，提示但不阻止（D62）；离职、任职结束与账号关联的结束先在事务外写意图证据，再提交，变更历史记录证据身份与版本（协议 15），整套恢复后依据证据重新办理；发件行在锁内按提交后编号，发布位置带纪元，事件只含可投影字段（协议 02）；本组件是**水位来源**（协议 02）；高可用部署中本组件的收紧事务同步提交到备库（D65，协议 15） |
| 命令与查询 | 入职、调岗、离职（生效日期）；任职查询（某人当前持有的岗位、某岗位的持有人）；补取（水位探测：只对声明订阅的服务身份开放，返回到回声为止的变更；[协议 02](../protocols/02-projections.md#来源水位)） |
| 事件 | 员工、任职与账号关联的状态事件；任职开始与结束（驱动授权的任职关联授予，D30；驱动审批任务重分配，协议 09）；水位回声（作为授权的内部来源，安全 03） |
| 必需依赖 | `mdm/org`、身份、授权 |
| 可选依赖与缺件 | `infra/audit`（兼任证据存储）：缺时收紧的意图走外部告警通道（协议 15） |
| 替换与 Fork | 同契约实现；与外部 HR 系统同步时以适配器写入 |
| 部署 | 读多写少；适合外壳 |
| 适用协议 | 02、07、08、13、16、安全 02、04、08（任职与授予的联动） |
| 范围 | 当前重建范围（新身份，D06） |
| 验证故事 | 审批人离职，待处理任务按岗位转给接任者；调岗后旧任职关联的授予自动撤销，新授予待确认（D30）；一人两个账号映射到同一员工，职责分离按人检查 |

## mdm/currency

| 项 | 内容 |
| --- | --- |
| 何时需要 | 所有使用金额的客户（单币种客户也需要币种定义） |
| 统一语言 | 币种（ISO 4217，最小单位、舍入方式、现金舍入单位）；汇率类型；汇率（日期、来源） |
| 拥有的数据 | 币种定义、汇率类型、每日汇率 |
| 不变量 | 同一类型、同一日期、同一币种对只有一个有效汇率；已被单据快照的汇率修改不影响单据（单据保存快照） |
| 命令与查询 | 维护币种与汇率；按日期与类型查询汇率 |
| 事件 | 汇率发布 |
| 必需依赖 | 身份、授权 |
| 可选依赖与缺件 | 汇率来源适配器：缺时人工维护 |
| 替换与 Fork | 同契约实现；汇率来源可替换 |
| 部署 | 极低负载；适合外壳 |
| 适用协议 | 02、14 |
| 范围 | 当前重建范围（原升级计划的方向） |
| 验证故事 | 外币订单快照汇率后汇率修改，订单金额不变；三位小数币种按其最小单位舍入 |
