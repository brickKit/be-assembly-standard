# 生产与资产

全部为远期；领料与完工入库只经库存写入，成本经存货成本组件进入财务。

## erp/manufacturing

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有生产加工的客户 |
| 统一语言 | 物料清单（BOM）与版本；工艺路线；生产工单；领料；完工；物料需求计划（MRP） |
| 拥有的数据 | BOM 与版本、工艺路线、工单与进度、MRP 运行结果（建议） |
| 不变量 | 工单绑定开工时的 BOM 版本；领料与完工经库存流水，制造不维护余额；MRP 只产生建议，下达由人确认 |
| 命令与查询 | BOM 维护；工单下达、领料、报工、完工；MRP 运行 |
| 事件 | 工单状态；报工事实（供成本） |
| 必需依赖 | `erp/inventory`、`mdm/product`、`mdm/org`、身份、授权 |
| 可选依赖与缺件 | `erp/costing`：缺时无工单成本；`erp/quality`：缺时无检验关卡；`erp/purchase`：MRP 采购建议无法下达 |
| 替换与 Fork | MRP 算法与排产是替换点（D27）；行业模型可 Fork |
| 部署 | MRP 批量计算较重；后台预算单独 |
| 适用协议 | 01、02、04（领料预占）、05（成本）、06、13、14、16 |
| 范围 | 远期 |
| 验证故事 | BOM 修改不影响已开工的工单；完工入库的应答丢失不重复入库 |

## erp/quality

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要检验与不合格品管理的客户 |
| 统一语言 | 检验计划；检验单；结果；不合格品；处置 |
| 拥有的数据 | 检验计划、检验单与结果、不合格品与处置记录 |
| 不变量 | 质量冻结通过库存的库存状态表达（经库存契约），质量组件不直接改余额 |
| 必需依赖 | `erp/inventory`、`mdm/product`、身份、授权 |
| 范围 | 远期 |
| 验证故事 | 检验不合格的批次被冻结后不能出库 |

## erp/maintenance

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有设备维护的客户 |
| 统一语言 | 设备；维护计划；维护工单；备件 |
| 拥有的数据 | 设备、维护计划与工单 |
| 不变量 | 备件消耗经库存出库；周期计划按定时槽位生成（协议 01） |
| 必需依赖 | 身份、授权 |
| 可选依赖与缺件 | `erp/inventory`：备件；缺时只记录不扣库存；`erp/asset`：设备与资产关联 |
| 范围 | 远期 |
| 验证故事 | 停机两天后补生成的计划工单不重复 |

## erp/asset

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要固定资产与折旧的客户 |
| 统一语言 | 资产卡片；折旧方法；折旧期间；盘点；处置 |
| 拥有的数据 | 资产卡片、折旧计划与计提记录、盘点与处置 |
| 不变量 | 每期折旧只计提一次；已关期间不再计提（协议 06） |
| 命令与查询 | 新增、变动、折旧计提、盘点、处置 |
| 事件 | 折旧与处置事实（供财务过账） |
| 必需依赖 | `erp/finance`、`mdm/org`、身份、授权 |
| 范围 | 远期 |
| 验证故事 | 折旧任务重跑不重复计提 |
