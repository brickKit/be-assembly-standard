# 生产与资产

全部为远期。领料与完工入库只经库存写入；工单成本、在制品与差异由存货成本组件计算后进入财务（协议 05b）；资产的折旧与处置按会计事实契约直接进入财务。

## erp/manufacturing

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有生产加工的客户 |
| 统一语言 | 物料清单（BOM）与版本；工艺路线；生产工单；领料；完工；委外加工（远期，材料存放在供应商处，用库存的货主与库位维度表达） |
| 拥有的数据 | BOM 与版本、工艺路线、工作中心（含成本费率）、工单与进度 |
| 不变量 | 工单绑定开工时的 BOM 版本；领料与完工经库存流水，制造不维护余额 |
| 命令与查询 | BOM 维护与查询（供计划展开）；工单下达、领料、报工、完工；事实的高点读取（写标记行并锁内编号，供成本组件关账前读取）与按序号补取（协议 06） |
| 事件 | 工单状态；报工、工时与完工事实（供成本计算工单成本与差异） |
| 必需依赖 | `erp/inventory`、`mdm/product`、`mdm/org`、身份、授权 |
| 可选依赖与缺件 | `erp/quality`：缺时无检验关卡；`erp/planning`（下游，读取 BOM、下达生产建议）：缺时工单由人直接创建；`erp/costing`（下游，消费报工事实）：缺时无工单成本 |
| 替换与 Fork | 工艺与报工方式按行业 Fork；MRP 与排产在 `erp/planning`（D71） |
| 部署 | 车间前台与报工为主；适合外壳或单跑 |
| 适用协议 | 01、02、04（领料预占）、05b（成本）、13、14、16；不是关账参与方（报工事实经成本组件，成本组件封存前读取本组件的事实序号，协议 06） |
| 范围 | 远期 |
| 验证故事 | BOM 修改不影响已开工的工单；完工入库的应答丢失不重复入库 |

## erp/quality

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要检验与不合格品管理的客户 |
| 统一语言 | 检验计划；检验单；结果；不合格品；处置 |
| 拥有的数据 | 检验计划、检验单与结果、不合格品与处置记录 |
| 不变量 | 质量冻结通过库存的库存状态表达（经库存契约），质量组件不直接改余额 |
| 命令与查询 | 检验计划维护；生成检验单（收货、工序、完工）；登记结果；不合格品处置（经库存契约改变库存状态） |
| 事件 | 检验结果；不合格品处置 |
| 必需依赖 | `erp/inventory`、`mdm/product`、身份、授权 |
| 可选依赖与缺件 | `erp/purchase`、`erp/manufacturing`（上游，只经事件）：收货、工序与完工生成检验单，缺哪个，那类检验就人工发起 |
| 适用协议 | 01、02、13、14、安全 01–09 |
| 范围 | 远期 |
| 验证故事 | 检验不合格的批次被冻结后不能出库 |

## erp/maintenance

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有设备维护的客户 |
| 统一语言 | 设备；维护计划；维护工单；备件 |
| 拥有的数据 | 设备、维护计划与工单 |
| 不变量 | 备件消耗经库存出库；周期计划按定时槽位生成（协议 01） |
| 命令与查询 | 设备与维护计划维护；维护工单的生成、执行与完工；备件领用 |
| 事件 | 维护工单状态；设备停机与恢复 |
| 必需依赖 | `mdm/product`（备件）、`mdm/org`（地点）、身份、授权 |
| 可选依赖与缺件 | `erp/inventory`：备件；缺时只记录不扣库存；`erp/asset`：设备与资产关联 |
| 适用协议 | 01、02、13、14、安全 01–09 |
| 范围 | 远期 |
| 验证故事 | 停机两天后补生成的计划工单不重复 |

## erp/asset

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要固定资产与折旧的客户 |
| 统一语言 | 资产卡片；资产购置（来自供应商票据或资产类收货）；折旧方法；折旧期间；盘点；处置；期初资产卡片 |
| 拥有的数据 | 资产卡片、折旧计划与计提记录、盘点与处置 |
| 不变量 | 每期折旧只计提一次；已关期间不再计提（协议 06） |
| 命令与查询 | 新增、资本化（订阅财务的“资产购置确认”）、变动、折旧计提、盘点、处置；期初卡片（上线窗口，协议 16）；关账参与（协议 06） |
| 事件 | 折旧与处置事实（按会计事实契约供财务过账，协议 05） |
| 必需依赖 | `mdm/org`、身份、授权 |
| 可选依赖与缺件 | `erp/finance`（下游，按会计事实契约接收；上游只经事件：供应商票据中标为资产购置的明细发布资产购置确认）：缺时资产只记卡片，不入账 |
| 适用协议 | 02、05、06、13、14、16、安全 01–09 |
| 范围 | 远期 |
| 验证故事 | 折旧任务重跑不重复计提 |
