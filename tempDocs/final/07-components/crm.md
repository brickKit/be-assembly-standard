# 客户关系

CRM 与 ERP 之间没有同步调用，只经事件协作；CRM 引用业务伙伴的客户角色与正式联系人（D01、D21），不复制身份权威。全部组件为远期，`crm/opportunity` 在当前重建范围。

## crm/lead

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有线索获取与转化流程的客户 |
| 统一语言 | 线索；来源；未核实的联络资料；去重；转化 |
| 拥有的数据 | 线索与其未核实的联络资料、去重与转化记录 |
| 不变量 | 转化时在伙伴主数据中新建或关联客户角色（经伙伴的接口），线索本身不成为客户身份权威；未核实的联络资料只有在核实后才写入伙伴的正式联系人 |
| 命令与查询 | 新建、分配、去重、转化 |
| 事件 | 线索转化 |
| 必需依赖 | `mdm/partner`、身份、授权 |
| 可选依赖与缺件 | `crm/campaign`：来源归因；缺时只记录来源文本；`crm/customer`、`crm/opportunity`：转化时同时建立客户关系与商机，缺时只建伙伴 |
| 替换与 Fork | 打分与分配规则是替换点 |
| 部署 | 低负载；适合外壳 |
| 适用协议 | 02、07、08、13、16 |
| 范围 | 远期 |
| 验证故事 | 重复线索合并；转化时客户已存在则关联不新建 |

## crm/customer

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要销售归属、公海、共享协作的客户 |
| 统一语言 | 客户关系（引用伙伴的客户角色）；负责人；公海与认领；共享；私有备注与关系评价 |
| 拥有的数据 | 负责人与归属历史、公海状态、共享记录（按安全 05 的机构共享）、私有备注 |
| 不变量 | 同一客户关系在同一销售组织内只有一个负责人；公海认领有上限与冷却；私有备注不同步到伙伴的公共字段 |
| 命令与查询 | 分配、转移、退回公海、认领、共享 |
| 事件 | 负责人变化（需要按客户负责人过滤的组件，例如销售，订阅它维护“客户 → 负责人”的关系投影，作为授权的关系维度；协议 13 的授权列只存行属主自己的事实） |
| 必需依赖 | `mdm/partner`、`mdm/employee`、身份、授权 |
| 可选依赖与缺件 | 无 |
| 替换与 Fork | 公海规则是替换点 |
| 部署 | 低负载；适合外壳 |
| 适用协议 | 02、07、13、安全 05 |
| 范围 | 远期 |
| 验证故事 | 负责人转移后旧负责人看不到客户；两人同时认领公海客户只有一人成功 |

## crm/opportunity

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要商机管理与销售预测的客户 |
| 统一语言 | 商机；阶段；赢单与输单；预测金额与概率 |
| 拥有的数据 | 商机、阶段历史、预测 |
| 不变量 | 阶段只按声明的顺序推进或明确回退；赢单后不再修改金额（修改需新商机或明确重开） |
| 命令与查询 | 维护商机；推进阶段；请求报价（发事件，销售生成带商机参考的报价草稿）；赢单与输单（手动，或按报价被接受、订单确认的事件标记，按客户的设置）；漏斗查询 |
| 事件 | 阶段变化、请求报价、赢单、输单 |
| 必需依赖 | `mdm/partner`、身份、授权 |
| 可选依赖与缺件 | `crm/customer`：负责人维度；缺时按创建人；`erp/sales`（只经事件）：消费请求报价；商机消费销售带商机参考的报价与订单事件，缺时只手工记录结果 |
| 替换与 Fork | 预测方法是替换点 |
| 部署 | 低负载；适合外壳 |
| 适用协议 | 02、07、08、13、安全 01–09 |
| 范围 | 当前重建 |
| 验证故事 | 请求报价事件重复投递只生成一张报价草稿；销售未安装时赢单正常完成 |

## crm/activity

| 项 | 内容 |
| --- | --- |
| 何时需要 | 记录拜访、电话、跟进的客户 |
| 统一语言 | 活动；时间线；关联对象 |
| 拥有的数据 | 活动记录 |
| 不变量 | 活动的可见性跟随关联对象（客户关系或商机）的授权 |
| 命令与查询 | 记录与修改活动；时间线查询（按客户、商机、联系人） |
| 事件 | 活动记录（供时间线与报表） |
| 必需依赖 | `mdm/partner`、身份、授权 |
| 可选依赖与缺件 | `crm/customer`、`crm/opportunity`：活动关联到客户关系与商机，缺时只关联伙伴 |
| 适用协议 | 02、07、11（活动可转层）、13 |
| 范围 | 远期 |
| 验证故事 | 无权查看客户的人看不到其活动 |

## crm/campaign

| 项 | 内容 |
| --- | --- |
| 何时需要 | 做营销活动与归因的客户 |
| 统一语言 | 活动；受众；触达；归因 |
| 拥有的数据 | 营销活动、受众名单、归因结果 |
| 不变量 | 触达遵守收件人的退订与合规同意 |
| 命令与查询 | 活动维护；受众生成；触达（经通知意图）；归因查询 |
| 事件 | 触达结果；归因 |
| 必需依赖 | 身份、授权 |
| 可选依赖与缺件 | 邮件与短信渠道：缺时不能触达 |
| 适用协议 | 01、02、10（触达经通知）、13、14、安全 01–09 |
| 范围 | 远期 |
| 验证故事 | 已退订的联系人不在受众中 |

## crm/case

| 项 | 内容 |
| --- | --- |
| 何时需要 | 有客户服务与工单的客户 |
| 统一语言 | 工单；服务目标；升级；解决 |
| 拥有的数据 | 工单、处理记录、服务目标计时 |
| 不变量 | 服务目标按工作日历计时（协议 14）；超时提醒与升级，不自动关闭 |
| 命令与查询 | 工单的建立、分派、处理、升级与解决；关联退货单（用户在销售中建立退货单，前端从工单带入工单参考）；服务目标查询 |
| 事件 | 工单状态；服务目标超时 |
| 必需依赖 | `mdm/partner`、`mdm/org`（工作日历）、身份、授权 |
| 可选依赖与缺件 | `erp/sales`（只经事件）：按协议 07 保存订单与退货单的引用投影；退货单记录工单参考，退货状态事件带回工单；缺时只记文本 |
| 范围 | 远期；现场服务（派工、备件消耗）登记为评估 |
| 验证故事 | 跨节假日的服务目标按工作日历计算；客户经工单退货，退货单在销售中批准，工单显示退货进度 |

## crm/commission

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要按规则计算销售佣金的客户 |
| 统一语言 | 佣金规则；计算期间；佣金结果；结算 |
| 拥有的数据 | 规则与版本、计算结果 |
| 不变量 | 计算以来源事实（出账或收款）为依据，来源更正时生成调整而不改写已结算结果 |
| 命令与查询 | 规则维护；计算运行；结果查询与确认；结算（发布结算事实） |
| 事件 | 佣金结算（供薪资）；结果调整 |
| 必需依赖 | `mdm/employee`（销售人员）、`mdm/currency`、身份、授权 |
| 可选依赖与缺件 | `erp/billing`、`erp/payment`（只经事件）：计算的来源事实，装配准入要求至少有一个（安全 09）；薪资（下游，只经事件）：结算事实并入薪资，由薪资过账，缺时转为报销或财务的人工应付；本组件不是会计事实的来源，也不参加关账 |
| 适用协议 | 01、02、13、14、安全 01–09 |
| 范围 | 远期 |
| 验证故事 | 账单红冲后生成负的佣金调整 |
