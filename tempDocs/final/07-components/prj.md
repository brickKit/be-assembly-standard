# 项目

全部为远期。

## prj/project

| 项 | 内容 |
| --- | --- |
| 何时需要 | 按项目管理计划、里程碑与成本的客户 |
| 统一语言 | 项目；任务与里程碑；预算；成本归集；成本费率；计费费率；出账方式（按里程碑、按工时与费用）；项目出账来源 |
| 拥有的数据 | 项目、计划、预算、计费费率与成本费率规则、成本归集结果、作为出账来源的可出账台账（里程碑；已批准、可计费的工时 × 计费费率；可转售的报销与采购） |
| 不变量 | 成本归集以来源事实（工时、报销、采购、领料）为依据，按事实 ID 去重；项目作为出账来源时由项目裁决可出账额度（协议 05） |
| 命令与查询 | 项目维护；费率维护；里程碑完成；来源认领（出账的请求，协议 05）；期初项目（上线窗口，协议 16）；关账参与（协议 06，项目的成本与收入事实进入财务时）；成本与预算查询 |
| 事件 | 里程碑完成；可出账额度变化（增量事实）；项目成本事实（按会计事实契约，供财务；项目收入与在制的入账规则为远期待定） |
| 必需依赖 | `mdm/org`、`mdm/currency`（预算与成本）、身份、授权 |
| 可选依赖与缺件 | `mdm/partner`：客户项目引用客户角色，内部项目不需要；`prj/timesheet`、`hrm/expense`、`erp/purchase`、`erp/inventory`（领料）：成本来源，只经事件；`erp/billing`（下游，向本组件认领）：按里程碑或按工时与费用出账，缺时不出账 |
| 替换与 Fork | 成本分摊规则是替换点 |
| 部署 | 低负载；适合外壳 |
| 适用协议 | 01、02、05、06、07、13、14、16 |
| 范围 | 远期 |
| 验证故事 | 同一工时事实重复到达只归集一次；里程碑出账不重复；同一批已批准工时只被一张账单认领 |

## prj/timesheet

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要记录与审批工时的客户 |
| 统一语言 | 工时单；期间；审批 |
| 拥有的数据 | 工时单与审批状态（只记工时；计费费率归项目，成本费率归项目的成本规则） |
| 不变量 | 批准后的工时修改走修订重审；已关期间的工时更正顺延 |
| 命令与查询 | 工时单的填写、提交、审批与修订；工时查询 |
| 事件 | 工时批准与修订（供项目的成本归集与可出账台账） |
| 必需依赖 | `mdm/employee`、身份、授权 |
| 可选依赖与缺件 | `prj/project`：缺时工时不归集到项目；`infra/workflow`（下游）：缺时审批在本组件页面中处理 |
| 部署 | 低负载；适合外壳 |
| 适用协议 | 01、02、09、13、14 |
| 范围 | 远期 |
| 验证故事 | 员工离职后其未批工时按岗位重分配审批 |
