# 分析

报表、自助 BI 与搜索只读各组件发布的数据集，不读业务表（[协议 13](../06-protocols/13-search-reports-and-datasets.md)）。

## ana/bi

| 项 | 内容 |
| --- | --- |
| 何时需要 | 所有需要报表与看板的客户（标准内置基础报表，D52） |
| 统一语言 | 数据集；指标与版本；报表；看板；订阅；完整水位 |
| 拥有的数据 | 数据集的存储（投影）、指标定义、报表与看板定义、订阅 |
| 不变量 | 查询时按当前授权编译；数据集带齐段谓词需要的全部授权列；受限用户查询时，完整水位不早于“当前 − F”，否则无法确认；“数据截至”使用完整水位；订阅按收件人生成 |
| 命令与查询 | 报表与看板查询；导出（后台）；订阅；数据集查询服务（供自助 BI） |
| 事件 | 无 |
| 必需依赖 | 身份、授权、各数据集的发布组件（D68 的例外：按客户装配的数据集清单明确列出） |
| 可选依赖与缺件 | 自助 BI 工具与适配：缺时只有内置报表 |
| 替换与 Fork | 数据集存储可从同库换到独立分析库或分析引擎，契约不变；BI 工具按路线选配 |
| 部署 | 查询与投影负载独立预算；按负载单跑 |
| 适用协议 | 02、11（历史数据集）、13、17 |
| 范围 | 是否进入当前重建范围随第 8 项的计划确认（标准版内置基础报表，D52）；身份保留，含义为数据集与报表服务 |
| 验证故事 | 撤权后刷新报表立即收窄；数据集有缺口时“数据截至”停在缺口前 |

## ana/search

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要全局搜索的客户 |
| 统一语言 | 搜索数据集；索引；摘要字段 |
| 拥有的数据 | 搜索索引（投影） |
| 不变量 | 查询时按当前授权过滤，授权列的新鲜度规则与 `ana/bi` 相同；删除与擦除同步到索引 |
| 必需依赖 | 身份、授权、各搜索数据集的发布组件（D68 的例外：按客户装配的数据集清单明确列出） |
| 替换与 Fork | 引擎从 PostgreSQL 全文检索换到专门引擎，契约不变 |
| 范围 | 远期（新身份） |
| 验证故事 | 结果打开时已无权，原组件拒绝 |
