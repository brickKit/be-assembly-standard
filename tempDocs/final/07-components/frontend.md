# 前端入口

入口按[协议 20](../../protocols/20-frontend.md) 构建与运行；前端不是业务权威，所有规则由后端执行。

## frontend/pc

| 项 | 内容 |
| --- | --- |
| 何时需要 | 办公室用户（几乎所有客户） |
| 统一语言 | 入口；页面模块；菜单；`features` 与 `permissions` |
| 拥有的数据 | 无业务数据；浏览器中只有界面状态与本地草稿 |
| 不变量 | 按客户基线构建时组合所需能力存在的页面模块；页面不接触令牌 |
| 必需依赖 | 身份（会话）、边缘入口、所选页面模块对应的后端组件 |
| 可选依赖与缺件 | 未选组件的页面不注册 |
| 替换与 Fork | 客户 Fork 或行业实现接替本入口，不影响其他入口 |
| 部署 | 静态资源由边缘或静态文件服务提供 |
| 适用协议 | 20 |
| 范围 | 当前重建（承接 `frontend/standard` 的 PC 部分） |
| 验证故事 | 未装库存时没有库存菜单；用户无权的菜单不显示且后端拒绝直接访问 |

## frontend/mobile

| 项 | 内容 |
| --- | --- |
| 何时需要 | 外勤、审批、移动查询 |
| 统一语言 | 同 PC；另有原生应用的安全存储与刷新令牌 |
| 拥有的数据 | 本地草稿 |
| 不变量 | 草稿按用户、法人、表单隔离；联网后由用户确认提交 |
| 必需依赖 | 身份、`infra/bff-mobile`、所选后端组件 |
| 替换与 Fork | 可单独替换 |
| 适用协议 | 20 |
| 范围 | 当前重建（承接 `frontend/standard` 的移动部分） |
| 验证故事 | 断网编辑草稿，联网后确认提交时权限已撤销被拒 |

## frontend/terminal

| 项 | 内容 |
| --- | --- |
| 何时需要 | 仓库与门店的共用终端 |
| 统一语言 | 共用终端；短会话；扫码作业 |
| 拥有的数据 | 本地草稿（缺省登出即清除） |
| 不变量 | 每人登录；他人看不到前一个用户的草稿 |
| 必需依赖 | 身份、`erp/inventory` 或 `erp/warehouse` |
| 替换与 Fork | 可单独替换 |
| 适用协议 | 20 |
| 范围 | 远期 |
| 验证故事 | 共用终端上用户乙看不到用户甲的草稿 |

## frontend/advanced

保留为行业或高级入口的候选身份；在相同入口、功能与权限满足时接替对应的标准入口，也可以并存于不同入口。
