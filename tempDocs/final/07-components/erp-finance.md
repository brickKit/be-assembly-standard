# 财务与结算

财务拥有总账、应收应付台账、核销与期间；信用、存货成本、客户出账、收付款、税计算各是独立可选的组件（D03、D46、D48、D47、D49），向财务提供可靠事实，不维护第二份账簿权威。

## erp/finance

| 项 | 内容 |
| --- | --- |
| 何时需要 | 需要会计账簿、应收应付的所有 ERP 客户 |
| 统一语言 | 科目表；凭证与分录；会计事实契约与过账规则；应收与应付未清项；预收与预收认领；预付与员工借款（借方未清项）；付款认领；资金调拨与科目收付的过账；人工未清项；维度目录与成本中心；递延计划；收货未开票的期末暂估；资产购置确认；核销与冲正；外币重估；会计期间与关账批次；供应商票据与贷项的登记与匹配（D50）；催款与对账单；期初 |
| 拥有的数据 | 科目表、过账规则与科目映射、凭证（每法人一个正式账簿，D51）、应收应付未清项与预收、付款认领台账、核销记录、重估记录、期间状态与关账批次、供应商票据与匹配结果、编号序列、分析维度目录与成本中心、递延计划 |
| 不变量 | 借贷平衡；凭证号按法人与期间连续（协议 14）；已关期间不能过账；核销在锁内完成，未清余额不为负；任何核销、冲销、调整、抵扣与新认领只用可用余额（未清余额减认领中），认领中的部分释放后才能另作他用（协议 05）；同一来源事实只入账一次（事实 ID 去重） |
| 命令与查询 | 按会计事实契约接收并过账；手工凭证；人工未清项的登记（增值税等应付、缺来源时的未清项，经审批）；维度目录与成本中心的维护；付款认领的认领、续期、确认、释放与冲回（收付款调用）；预付申请与借款申请的撤回（采购与报销调用，可用余额等于未清余额才接受）；预收放行认领的认领、续期、确认、正式化、释放与冲回（销售在提交放行交货之前认领与确认，放行提交后正式化）；按订单的放行台账（接受销售的期初放行台账命令，协议 16；收款、退款、非放行明细的核销与贷记都在台账上记账）；预付申请与借款申请的登记（采购订单或借款单发起），付款正式化后形成已付余额，已付余额在票据匹配或报销批准时抵扣；到期未清项与订单预收余额查询；核销与冲正；外币重估与收货未开票暂估的运行（期末步骤）；关账批次（协议 06）；重开；供应商票据与贷项的登记与匹配；催款与客户对账单（经通知意图发出）；员工往来角色在未清项结清后的退役（经伙伴接口，或转人工待办）；账簿、余额、账龄查询 |
| 事件 | 凭证过账；应收结清、减少与重开（供信用，协议 05）；预收形成与变化；资产购置确认（供资产组件）；票据单价确认、票据单价调整（价格折让与补差票）与费用票据确认（供成本）；应收已形成；已核销；关账的“请求封存”“请求解封”与“已关闭”（参与方订阅，协议 06）；维度目录（投影）；期间状态 |
| 必需依赖 | `mdm/org`、`mdm/partner`、`mdm/currency`、身份、授权 |
| 可选依赖与缺件 | 会计事实的来源（按共享契约发布，按客户装配的清单列出：`erp/billing`、`erp/payment`、`erp/costing`、`hrm/expense`、各国薪资实现（或 `hrm/payroll-core`）、`erp/asset`）：缺哪个，相应的事实就不存在，由手工凭证或人工未清项处理，并在报表中注明；`erp/tax`：进项税的计算与校验，缺时人工录入；`erp/purchase`：供应商票据匹配的依据（已到货、已验收数量与金额），缺时供应商票据只登记、不做采购匹配；`erp/credit`（下游，消费应收结清与重开）：缺时没有信用释放；`erp/budget`（下游，只经事件：应付过账事件带预算分支）：缺时不消耗预算 |
| 替换与 Fork | 需要多账簿或特殊会计准则的客户选择专项财务实现或 Fork（D51） |
| 部署 | 事务密集、期末批量；单跑或外壳按负载 |
| 适用协议 | 01、02、03、05、06、07、10（催款经通知）、11、13、14、15、16（期初凭证与未清项）、安全 01–09 |
| 范围 | 当前重建 |
| 验证故事 | 同一收款被两次核销时只成功一次；关账期间迟到的成本调整顺延；期初应收控制科目等于未清项合计才激活 |
